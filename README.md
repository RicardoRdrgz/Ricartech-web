## Descripción

Web corporativa estática para **Ricartech**, servicio de reparación y mantenimiento informático a domicilio en Sitges (Barcelona) y la comarca del Garraf.

El sitio está diseñado como un albarán de taller: papel hueso, tinta negra y un único acento azul. Prioriza la claridad de los precios y permite pedir presupuesto sin llamadas previas. Está disponible en **español** (`/`) y **catalán** (`/ca/`), con contenido equivalente y enlaces `hreflang` recíprocos.

Optimizada para **SEO local**, **accesibilidad** y **rendimiento**. Sin frameworks en producción: HTML, CSS y JavaScript vanilla.

🌐 **Web en producción:** [ricartech.es](https://ricartech.es)

---

## Qué incluye

- **Presupuesto en 3 pasos**: servicio, datos de contacto y resumen editable antes del envío.
- **Calculadora orientativa** con precios reales de mano de obra y etiquetas «desde».
- **Contacto directo** por WhatsApp y formulario con RGPD y ticket de seguimiento.
- **Páginas de servicio** propias, orientadas a búsquedas locales.
- **Aviso legal, privacidad, cookies y condiciones de contratación** en ambos idiomas.

## Tecnologías

| Capa | Tecnología |
|:---|:---|
| Generación | Python estándar (`tools/build.py`) |
| Marcado | HTML5 semántico y JSON-LD (Schema.org) |
| Estilos | CSS vanilla, sin frameworks |
| Interactividad | JavaScript vanilla: calculadora, formulario y borrador |
| Tipografía | Archivo e IBM Plex Mono, autoalojadas en WOFF2 |
| Datos | Supabase para las solicitudes |
| Infraestructura | GitHub Pages + GitHub Actions y Cloudflare (HTTPS, cabeceras y Bot Fight Mode) |
